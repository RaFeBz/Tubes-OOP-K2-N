# Tugas Besar AP

Starter repository untuk **IF2110 Algoritma dan Pemrograman
2026/2027**. Berisi contoh struktur proyek C, Makefile, serta sample data.

Struktur folder boleh disesuaikan dengan rancangan kelompok.

```sh
make
make run
```

`make run` menjalankan aplikasi kelompok melalui `bin/nangornotes`.

## Struktur Folder

```text
.
├── Makefile
├── README.md
├── src/
│   ├── main.c
├── config
└── doc/                      # Laporan dan dokumentasi kelompok
```
